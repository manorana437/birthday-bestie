# Birthday Bestie — final React website

This is the final version based on the supplied heart-animation video.

### Included
- React + Vite
- HTML/CSS/JavaScript
- The supplied heart animation used as the cinematic opening background
- Romantic purple/pink grade, vignette and floating sparkles
- Animated “Happy Birthday My Bestie” title
- Working “Open your surprise” transition
- Your supplied bestie photo
- Working “Read my message” reveal
- Responsive mobile and desktop layout

### Run
Install Node.js 18+ and then:

npm install
npm run dev

For production:

npm run build

The production output is in `dist/`.
